Overview

DannyTrades Signal Automation is a private automation tool that monitors authorized Gmail emails and Google Drive images to extract structured trading signal data from DannyTrades Patreon research emails.

The application operates exclusively within the boundaries of permissions explicitly granted by the user via Google OAuth. It is built for a single authorized user and processes only designated data sources related to the DannyTrades signal intelligence pipeline.

This tool does not collect, store, or monetize any personal data. All processing is automated and occurs within authorized, secure service boundaries only.
2

Data We Access

The application requests access only to the following data, strictly limited to what is necessary to perform its function:

Data Type Access Level Purpose
Gmail emails (specific sender) Read-Only Extract DannyTrades Patreon signal emails
Google Drive images (designated folder) Read-Only Process chart images for visual signal extraction
Google Sheets (user-owned file) Read + Write Write structured extracted data for user review
Google account email address Read-Only Identify the authorized account for OAuth

No other Gmail messages, Drive files, or account information outside the above scope is accessed, read, or processed.

3

How We Use Data

Data accessed through this application is used solely for the following automated processing steps:

  • Ingesting incoming DannyTrades Patreon emails from a dedicated Gmail inbox
  • Classifying email content type (ticker signals, market commentary, trade calls, etc.)
  • Sending email body text to Claude AI for structured JSON extraction of trading signal fields
  • Reading chart images from a designated Google Drive folder for visual signal extraction via Claude Vision
  • Writing the extracted, structured data into a Google Sheets dashboard owned and controlled by the user

No data is used for advertising, profiling, analytics, or any purpose beyond the above automated extraction workflow.

Data Storage

Raw email content and chart images are processed transiently and are not permanently stored by the application or its developer.

  • Email bodies are passed to Claude API for extraction and are not retained after processing completes
  • Chart images are read from Google Drive and processed via Claude Vision; image data is not saved to any external location
  • Only the extracted structured data (candle signals, price levels, narratives, whale accumulation, etc.) is permanently stored — in a Google Sheets file owned and controlled entirely by the user
The only persistent storage is your own Google Sheets file. You retain full ownership and control over that data at all times.

7

Security

The following security practices are applied throughout this application:

  • Only the minimum required OAuth scopes are requested — gmail.readonly, drive.readonly, and Sheets access
  • No credentials, passwords, or API keys are manually stored or exposed in application code
  • All data transmission occurs over encrypted HTTPS connections via authorized APIs
  • OAuth access can be revoked at any time from your Google Account without any action required from the developer
  • Email deduplication hashing (MD5/SHA-256) prevents reprocessing, reducing unnecessary data exposure

  • Contact: Reach the developer at any time to request information about data handling or to request changes
9

Scope Justification

This application requests the drive.readonly Google OAuth scope for the following specific and limited purpose:

The Make.com "Watch Image" module monitors a designated Google Drive folder (DannyTrades_Charts) to detect newly uploaded chart images. When a new image is found, it is read and passed to the Anthropic Claude Vision API for visual trading signal extraction — identifying candle type, ribbon state, POC color, and whale accumulation percentage. The extracted values are written to the user's Google Sheets dashboard only.

The drive.readonly scope is the minimum necessary for this functionality. The application:

  • Only monitors a single, user-designated folder — not the full Google Drive
  • Only reads image files — no documents, spreadsheets, or other Drive content is accessed
  • Does not modify, delete, move, or share any Drive files
  • Does not store or transmit Drive content beyond the single Claude Vision API call required for extraction
  • Uses read-only access exclusively — no write permissions to Google Drive are requested

This scope is essential to enable automated chart image processing, a core feature of the DannyTrades signal extraction pipeline that cannot be achieved without Drive read access.
